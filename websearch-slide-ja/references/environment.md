# 実行環境ごとの読み替え（v0.8.4）

SKILL.md と他の references は、ツール名や保存先を**操作の名前**（「選択式で確認する」
「成果物を保存して提示する」など）で書いている。実際に使うツールとパスは、この表で読み替える。

スキルを開始したら最初にこの表を見て、**いまの環境で使える手段を確かめる**。
表にあるツールが見当たらないときは「その他」の列の方法で進める（作業を止めない）。

---

## 1. 読み替え表

| 操作 | Claude.ai | Claude Code | その他（GitHub Copilot / Codex / Antigravity など） |

## 2. 質問のしかた（全環境共通）

- 1 回の質問は **2〜4 択**に収める。5 択以上にしない（最も制約の強い環境に合わせる）
- SKILL.md が「逐次 2 回」と書いている箇所は、1 回にまとめず 2 回に分ける
  （先の回答で後の質問が不要になることがあるため）
- 複数の質問を 1 回の呼び出しにまとめられる環境でも、**前の回答に依存する質問**はまとめない
- 質問文・選択肢はユーザーの言語（既定は日本語）で書く
- 選択式の質問ツールが無い環境では、次の形で本文に書いて返答を待つ

```
スライド作成にどの情報を使いますか？
1. 会話の内容だけでOK
2. Web検索も追加する（会話 ＋ 検索）
3. Web検索メインで（検索中心）
番号でお答えください。
```

- 返答を得られない環境（非対話の実行など）では、勝手に進めず、確認が必要な項目を
  一覧にして止まる。ユーザーが依頼文や設定で先に答えを示している項目は、質問を省略してよい

## 3. 手段が無いときの進め方

| 無いもの | 進め方 |
|---|---|
| Web 検索 | Step 1-A の質問の代わりに「この環境では Web 検索ができません」と伝え、「会話の内容だけで進める／作成を中止する」の 2 択で確認する。検索したふりをしない（架空の出典を作らない） |
| 画像検索 | 画像収集をスキップし、その旨を完了時に伝える。ビジュアル方針の「グラフ作成＋画像あり」が選ばれた場合は「画像なし」として扱う |
| シェル実行 | CLI 診断ができないため、レガシートラックで進める。`validate-output.sh` と `capture.mjs` も実行できないので、自己検証（Step 5-B）はチェックリストを目で確認するだけにし、完了報告の 6 に「見た目の目視確認、機械的な検証（この環境ではシェルを実行できません）」と書く |
| Playwright（撮影） | `capture.mjs` が終了コード 3 を返す。撮影を飛ばし、完了報告の 6 に「見た目の目視確認（Playwright が無いため撮影していません）」と書く。**自動でインストールしない** |
| ファイルの保存 | `.md` と `.html` の内容を本文にそのまま出力し、ファイルとして保存していないことを伝える |

## 4. 保存と提示（全環境共通）

- ファイル名は `{テーマ}-slides.html` と `{テーマ}-slides.md`
- **`.md` と `.html` の両方**を保存して提示する（`.html` を先に）
- 既に同名のファイルがある場合は、上書きしてよいかを確認する。ただし同じ会話の中で
  自分が作ったファイルの再生成（MD を直して再変換）は、確認なしで上書きしてよい
- 保存先のパスを本文に書くときは、ユーザーが開ける形（相対パスなど）で書く
- スキルのフォルダ（`references/`・`assets/`）の中には成果物を保存しない
