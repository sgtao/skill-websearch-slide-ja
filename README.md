# skill-websearch-slide-ja

Web検索・Markdown・会話履歴・CSVなど多様な入力からスライド形式HTMLを生成するClaude.aiスキル。

## 使い方のトリガー例

### スラッシュコマンド
```
/websearch-slide-ja
前述までの会話履歴をスライド資料にしてください
```

### 自動判定
> 「〇〇についてスライドにまとめて」「プレゼン資料にして」
> 「このMDをスライドに変換して」「Markdownからスライドを生成して」
> 「この会話をスライドにして」「CSVからスライドを作って」
> 「スライドHTMLをMDに逆変換して」「3枚目を2カラムにして」

## 特徴

### 入力と生成
- Web検索による情報収集 → 構造化 → HTMLスライド生成を一気通貫で実行
- **スライドMarkdown中間形式** — .md と .html を両方出力。MDを編集して再変換可能。HTML→MD逆抽出にも対応
- **多様な入力の受け入れ** — 未準拠Markdown・会話履歴・プレーンテキスト・CSVを自動判定し、想定様式MDへ変換して確認後にHTML生成
- **作成目的に応じたトーン最適化** — 自己学習・振り返り用／社内共有・勉強会用／SNS発信・顧客プレゼン用の3目的から選択。構成・強調・引き算を自動調整

### テーマ・デザイン
- ライト/ダークテーマ切り替え対応
- **カラーパレット5色切替** — 🌊 Ocean / 🌲 Forest / 🌅 Sunset / 🍇 Plum / ⬛ Graphite（localStorage 保持・印刷にも反映）
- **レイアウトバリアント** — `two-col`（2カラム化）/ `title-xl`（タイトル拡大）/ `compact`（高密度）をMDディレクティブで指定
- **新テンプレート2種** — Feature ショーケース型（左ライト/右ダーク2カラム）、Before/After比較型（ドーナツ×2）

### グラフ・図解
- **SVGグラフを自動生成**（横棒・折れ線・ドーナツ・散布図）— 外部ライブラリ不使用・完全自己完結
- **インラインSVG図解** — 横フロー／縦レイヤー／サイクルの3パターン。Mermaidサブセットにも対応（変換時にインラインSVG化）
- ライト/ダーク両テーマでグラフ・図解の色が自動追従

### エクスポート・検証
- **PDF/PNGエクスポート** — `P` PDF / `Shift+S` PNG / `Shift+P` 全スライドZIP。📥 メニューからも操作可能
- **大量コンテンツの自動対応** — `slide-fit` クラスで一覧モード時にコンテンツ全体を表示
- **品質チェックスクリプト** — `validate-output.sh` で10カテゴリ自動検証（HTML構文・必須要素・画像形式・禁止ライブラリ等）
- 利用者の職種別の検索クエリ最適化（エンジニア・PM・マーケ等）

### このスキルが目指すもの

単なる検索結果の要約ではなく、
「収集 → 分析 → スライド化」までを一度の指示で完結させることを目的としています。

### 出力イメージ

ブラウザで動作するインタラクティブなHTMLプレゼンテーションを生成します。  
キーボード操作（`← →` ナビ / `Space` 次へ / `F` フルスクリーン / `V` 一覧切替 / `P` PDF / `Shift+S` PNG / `Shift+P` ZIP）、テーマ切替に対応しており、
HTMLファイルとして共有・配布できます。

## インストール

### for [Claude.ai](https://claude.ai/)
スキルフォルダ`websearch-slide-ja`をZIPファイルにして、[カスタマイズ＞スキル](https://claude.ai/customize/skills)に追加してください。

### for Claude Code
スキルフォルダごと `~/.claude/skills/` に配置してください。
