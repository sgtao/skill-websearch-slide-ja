# Usage Guide — 使い方と既定値の雛形（v0.9.0）

`workflows/help.md`（使い方を答える）と `workflows/create.md`「既定値の読み取り」から参照する。

---

## できることと頼み方

| できること | 頼み方の例 | 出てくるもの |
|---|---|---|
| テーマから作成 | 「○○ についてスライドにまとめて」「この会話の内容をスライドにして」 | `.md` と `.html` |
| MD から変換 | スライドMD を添付して「このMDをスライドに変換して」。箇条書きのメモ・CSV・会話の文章でも可（先にスライドMD の案を見せて確認する） | `.html`（と整えた `.md`） |
| HTML から MD に戻す | スライドHTML を添付して「このスライドHTMLをMDに逆変換して」 | `.md` |
| 作ったスライドの修正 | 「3 枚目を 2 カラムにして」、または `.md` を編集して「変換して」 | 再生成した `.html` |

- テーマから作るときは、作成前に 作成可否・目的・情報ソース・ビジュアル方針を選択式で確認する
  （下の既定値を書いておくと、書いた項目の質問を省ける）
- 生成のたびに、完了報告（生成物・トラック・lint・要確認・情報ソース・未実施の検証・次にできること）を出す
- 出典でもユーザー提供でも確認できない数値・固有名詞は、値を書かずに `（要確認: …）` と表示する

## 既定値の雛形

Claude Code の `CLAUDE.md`、Claude.ai のプロジェクト指示（instruction）のどちらにも貼れる。
**必要な行だけ**残し、値を自分の用途に書き換える。`#` 以降は選べる値の説明。

```markdown
## スライド作成（websearch-slide-ja）の既定値
- 作成目的: 社内共有・勉強会用          # 自己学習・振り返り用／社内共有・勉強会用／SNS発信・顧客プレゼン用
- 想定読者・自分のロール: エンジニア
- 情報ソース: 会話＋Web検索             # 会話のみ／会話＋Web検索／Web検索メイン
- ビジュアル: グラフ作成＋画像なし       # グラフ作成＋画像あり／グラフ作成＋画像なし／テキストのみ
- パレット: ocean
- 枚数の目安: 8〜12枚
- 保存先: docs/slides/
- スピーカーノート（note:）: 数値の取得時点と根拠を書く
- 作成前の確認: 既定値がある項目は質問を省略し、一覧で確認だけする
```

## 既定値の項目と、スキルでの扱い

見出しが「スライド作成（websearch-slide-ja）の既定値」である一覧を、既定値として読む。

| 項目 | 省略される質問・変わる動作 | 書けない値のとき |
|---|---|---|
| 作成目的 | Step 0 の呼び出し2（作成目的） | 3 つの目的のどれにも当たらなければ、従来どおり質問する |
| 想定読者・自分のロール | Step 1-B のロール推定・ヒアリング | `role-signals.md` のカテゴリに当たらなければ「汎用」 |
| 情報ソース | Step 1-A の 3 択（下限チェックは省略しない） | 3 つのどれにも当たらなければ質問する |
| ビジュアル | Step 1-C のビジュアル方針の確認（検索フレーズの提示は省略しない） | 3 つのどれにも当たらなければ質問する |
| パレット | frontmatter の `palette` | そのトラックで使えない ID なら `ocean` にして、その旨を伝える |
| 枚数の目安 | Step 3 の枚数（実効仕様の目安の範囲に丸める） | 範囲の外なら、近い側に丸めて、その旨を伝える |
| 保存先 | 成果物（`.md`・`.html`）の保存先。`.work/` はその隣 | 書き込めないフォルダなら、環境の既定の保存先にして、その旨を伝える |
| スピーカーノート（note:） | `note:` に書く内容の方針（CLIトラックで `note:` が使えるときだけ） | – |
| 作成前の確認 | 動作の説明として置く行。この行が無くても、既定値がある項目は質問を省略し、一覧で 1 回確認する（`workflows/create.md`「既定値の読み取り」） | – |

- **作成可否（Step 0 の呼び出し1）は省略しない**。やめる選択肢は必ず残す
- 既定値は質問を省くためのものであり、内容の確認を省くものではない。確認できない内容を書かない規則
  （`workflows/write-md.md`「Step 4-A」）と、完了報告・自己検証は既定値にかかわらず行う
- 依頼の文に既定値と違う指定があるときは、**依頼の文を優先**する（例: 既定値は「会話＋Web検索」だが、
  依頼が「検索なしで」）
